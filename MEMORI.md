## Struktur Penting
- `lib/main.dart` — entry point aplikasi; membungkus `MyApp` dengan `ProviderScope` (satu-satunya `ProviderScope` di aplikasi)
- `lib/app.dart` — root widget (`MyApp`, `ConsumerWidget`); `themeMode` reaktif dari `ref.watch(temaProvider).asData?.value ?? ThemeMode.system`; menyediakan `theme`/`darkTheme` ke `MaterialApp`
- `lib/home.dart` — halaman utama (`MyHomePage` dan `_MyHomePageState`); memuat `NavigationBar` 4 tab (Dashboard, Biodata, Impian, Lainnya) mengikuti pola `docs/lib.md`; tab selain Dashboard placeholder, tab "Lainnya" kini menampilkan `PengaturanScreen`
- `lib/fitur/pengaturan/notifier/tema_notifier.dart` — `TemaNotifier` (`@Riverpod(keepAlive: true)`, `AsyncNotifier<ThemeMode>`); memuat/mengubah mode tema (Terang/Gelap/Ikuti sistem) dan mempersistenkannya via `shared_preferences` (kunci `kunci_mode_tema`); file `tema_notifier.g.dart` hasil generate (jangan diedit manual); dipindah dari `tema/tema_provider.dart` pada sesi_21 (2026-11-14)
- `lib/fitur/pengaturan/screens/pengaturan_screen.dart` — layar `PengaturanScreen` (`ConsumerWidget`; pilihan mode tema; disematkan sebagai konten tab, tanpa `Scaffold`/`AppBar` sendiri)
- `lib/fitur/statistik/screens/statistik_screen.dart` — layar `StatistikScreen` minimal (disematkan sebagai tab, tanpa `Scaffold`/`AppBar` sendiri); memuat `SpesifikasiBateraiSection` dan `MemoriPenyimpananSection`
- `lib/fitur/statistik/widgets/spesifikasi_baterai_section.dart` — section "Spesifikasi Baterai" (Android-only; tombol muat ulang; fallback "tidak didukung" di iOS/web; `Tidak diketahui` untuk nilai tidak valid)
- `lib/fitur/statistik/data/baterai_repository.dart` — `BateraiRepository` (guard `kIsWeb`/`defaultTargetPlatform != TargetPlatform.android`; nilai 0/-1/`unknown` → `Tidak diketahui`)
- `lib/fitur/statistik/model/baterai_info.dart` — DTO `BateraiInfo` (kapasitas tersisa mAh, level %, status/sumber charger, health, suhu, tegangan, teknologi)
- `lib/fitur/statistik/notifier/baterai_notifier.dart` — `BateraiNotifier` (`@Riverpod(keepAlive: true)`, `muatUlang()` via `AsyncValue.guard`); file `baterai_notifier.g.dart` hasil `build_runner`
- `lib/fitur/diagnostik/daftar_tes.dart` — `TesDiagnostik` + `kDaftarTes` (9 tes: id, label, ikon)
- `lib/fitur/diagnostik/model/hasil_tes.dart` — DTO hasil tes: `enum StatusTes { lulus, gagal, tidakTersedia }`, `HasilTes` (id, label, status)
- `lib/fitur/diagnostik/screens/diagnostik_screen.dart` — `DiagnostikScreen` (grid `GridView.count` 3 kolom; lencana status per kartu; AppBar action "Ringkasan"; tombol pop mengembalikan `HasilTes`); Android-only
- `lib/fitur/diagnostik/screens/ringkasan_screen.dart` — `RingkasanScreen` (daftar hasil per tes + "N lulus / M gagal / K tidak tersedia"; tanpa persistensi)
- `lib/fitur/diagnostik/screens/tes/*_test_screen.dart` — 9 layar tes: `warna_layar`, `dead_pixel`, `multi_touch`, `kecerahan`, `getar` (HapticFeedback), `audio_speaker` (audioplayers + `assets/audio/nada_uji.wav`), `audio_mikrofon` (record + playback; izin `RECORD_AUDIO` saat tes), `senter` (torch_light `CameraManager.setTorchMode`, tanpa izin CAMERA), `tombol_volume` (EventChannel `spektra/tombol_volume`; `MainActivity.kt` memakai `dispatchKeyEvent`)
- `lib/fitur/diagnostik/widgets/pesan_hanya_android.dart`, `tes_footer.dart` (baris Lulus/Gagal/Tidak tersedia), `status_tes_badge.dart` — widget bersama fitur diagnostik
- `assets/audio/nada_uji.wav` — nada uji sine 440 Hz, 2 detik (aset baru; terdaftar di `pubspec.yaml`)
- `lib/fitur/statistik/model/memori_info.dart` — DTO `MemoriInfo` (RAM total/tersedia/terpakai MB, indikator RAM rendah, penyimpanan total/bebas/terpakai byte; seluruh field nullable)
- `lib/fitur/statistik/data/memori_repository.dart` — `MemoriRepository` (guard `kIsWeb`/non-Android → `null`; `DeviceInfoPlugin().androidInfo`; nilai negatif → `null`; selisih hanya bila operand valid; kegagalan → `null` + `debugPrint`)
