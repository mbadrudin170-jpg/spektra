# Spektra

**Know Your Device.**

Spektra adalah aplikasi Android berbasis Flutter untuk menampilkan informasi spesifikasi perangkat, memantau kondisi hardware, dan menyediakan alat diagnostik untuk menguji respons serta fungsi berbagai komponen perangkat.

## Fitur Utama

- Informasi perangkat dan sistem operasi.
- Informasi CPU, RAM, dan penyimpanan.
- Informasi layar dan baterai.
- Informasi dan pengujian sensor.
- Pengujian fungsi komponen perangkat seperti layar, kamera, dan audio.
- Monitoring hardware secara real-time.
- Pemeriksaan konektivitas jaringan.

## Teknologi

- Flutter & Dart
- Kotlin (Android Native)
- Android System APIs
