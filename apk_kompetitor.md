# Daftar Aplikasi Kompetitor — Spektra (Know Your Device)

> Daftar aplikasi serupa Spektra: aplikasi Android untuk informasi spesifikasi perangkat, monitoring hardware, dan alat diagnostik perangkat ("Know Your Device"). Ringkasan menyebut fitur relevan Spektra (info CPU/RAM/penyimpanan/baterai/layar/OS/kernel/sensor/termal/benchmark, diagnostik layar/kamera/audio/sensor, uji jaringan, monitoring realtime, widget info perangkat).
>
> Aturan penandaan: seluruh listing baru diberi `Status Analisa = Belum Dianalisa`. Status `Sudah Dianalisa` hanya boleh diset oleh perintah `riset_kompetitor.md`.
>
> Riset dikerjakan satu store per iterasi, berurutan: Google Play Store → F-Droid → GitHub → Apple App Store → Samsung Galaxy Store → Mi/GetApps → Oppo App Market → store lainnya. Berkas ini diperbarui setelah tiap store selesai.
